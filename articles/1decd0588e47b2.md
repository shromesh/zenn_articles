```json:left/right option -> eisuu/kana
{
    "description": "left/right option -> eisuu/kana",
    "manipulators": [
        {
            "from": {
                "key_code": "left_option",
                "modifiers": {
                    "optional": [
                        "any"
                    ]
                }
            },
            "parameters": {
                "basic.to_if_held_down_threshold_milliseconds": 100
            },
            "to": [
                {
                    "key_code": "left_option",
                    "lazy": true
                }
            ],
            "to_if_alone": [
                {
                    "key_code": "japanese_eisuu"
                }
            ],
            "to_if_held_down": [
                {
                    "key_code": "left_option"
                }
            ],
            "type": "basic"
        },
        {
            "from": {
                "key_code": "right_option",
                "modifiers": {
                    "optional": [
                        "any"
                    ]
                }
            },
            "parameters": {
                "basic.to_if_held_down_threshold_milliseconds": 100
            },
            "to": [
                {
                    "key_code": "right_option",
                    "lazy": true
                }
            ],
            "to_if_alone": [
                {
                    "key_code": "japanese_kana"
                }
            ],
            "to_if_held_down": [
                {
                    "key_code": "right_option"
                }
            ],
            "type": "basic"
        }
    ]
}
```

```json:escキーを押したときに英数キーも送信する（vim用）
{
    "description": "escキーを押したときに、英数キーも送信する（vim用）",
    "manipulators": [
        {
            "from": {
                "key_code": "escape"
            },
            "to": [
                {
                    "key_code": "escape"
                },
                {
                    "key_code": "japanese_eisuu"
                }
            ],
            "type": "basic"
        }
    ]
}
```

```json: Change 'c' to 'k' when input source is Japanese and no modifier key pushed
{
    "description": "Change 'c' to 'k' when input source is Japanese",
    "manipulators": [
        {
            "type": "basic",
            "from": {
                "key_code": "c"
            },
            "to": [
                {
                    "key_code": "k"
                }
            ],
            "conditions": [
                {
                    "type": "input_source_if",
                    "input_sources": [
                        {
                            "language": "^ja$"
                        }
                    ]
                }
            ]
        }
    ]
}
```
